# 测试用例工作面改版设计

## 背景

当前 TestOps 已具备测试用例列表、在线编写、详情编辑、评审发布、上传资料生成、导入用例等能力，但这几块界面仍然分散在不同的视觉模型中：

- 测试用例列表页更像轻量卡片清单
- 在线编写页偏工程化草稿表单
- 详情页与评审页的编辑体验割裂

用户希望参考已有企业测试平台的工作面，统一为更专业的测试用例管理体验，同时明确保留当前已有流程能力，尤其是：

- 上传资料生成
- 导入用例
- 预览评审
- 当前评审与发布链路

本次改版不是减少功能，而是在保留现有功能的前提下，重构测试用例相关页面的信息架构、布局和交互。

## 目标

本次改版的目标是：

1. 将测试用例列表页、在线编写页、用例详情页统一成同一套企业测试平台风格。
2. 列表页升级为真实可筛选的目录树 + 表格列表工作面。
3. 在线编写页和详情页升级为双栏编辑器，左侧编辑核心内容，右侧管理基础信息。
4. 为测试用例引入真实目录结构，支持两级目录：一级目录 / 二级目录。
5. 保留并重新安置当前已有流程入口，不影响上传资料生成、导入用例、预览评审、评审发布等功能。

## 非目标

本次不包含以下内容：

- 不改动项目工作台主流程定义
- 不移除现有评审页与发布能力
- 不引入无限级目录
- 不在本次中实现全新的富文本编辑器体系
- 不改变测试用例后端核心业务含义，如状态流转、发布逻辑、自动化生成逻辑

## 设计原则

### 1. 工作面优先

页面的首要任务是帮助 QA 快速定位、创建、编辑和筛选用例，而不是展示装饰性信息。

### 2. 功能保留但重新排位

上传资料生成、导入用例、预览评审等现有能力必须保留，但应放到顶部工具区、流程区或侧栏动作区，而不是混进主编辑区域。

### 3. 编辑与管理分离

用例正文、步骤、预期结果属于主编辑工作；编号、优先级、目录归属、标签等属于侧栏管理信息，两者视觉上必须分层。

### 4. 目录真实化

目录不是仅供展示的前端树，而是项目维度下真实存在的数据结构，可以驱动筛选、统计和后续扩展。

### 5. 中文优先

整套页面继续保持中文主语境，标签与按钮尽量使用测试管理场景中更专业、更稳定的中文词汇。

## 页面范围

本次统一样式和结构的页面包括：

1. 测试用例列表页 `/projects/[projectId]/test-cases`
2. 新建测试用例页 `/projects/[projectId]/test-cases/new`
3. 测试用例详情页 `/projects/[projectId]/test-cases/[testCaseId]`

关联受影响但不重做为主战场的页面：

1. 项目工作台中的测试用例入口
2. 评审页 `/projects/[projectId]/review`
3. 上传资料生成与导入用例的入口组件

## 信息架构

### 一、测试用例列表页

列表页改为“左侧目录树 + 顶部工具栏 + 右侧表格区”的结构。

#### 左侧目录树

左侧固定展示项目内测试用例目录树，采用两级结构：

- 一级目录
- 二级目录

行为规则：

- 点击一级目录，右侧展示该一级目录下所有用例，包含其二级目录中的用例
- 点击二级目录，右侧只展示该二级目录下的用例
- 未归类用例统一归入“未分类”
- 每个目录节点显示用例数量
- 支持展开 / 收起二级目录

#### 顶部工具栏

顶部工具栏保留现有能力，并重新组织为两层：

- 主操作层：
  - 新建用例
  - 导入用例
  - 上传资料生成
- 筛选层：
  - 视图范围，例如“所有用例”
  - 状态筛选
  - 搜索框
  - 更多操作入口
  - 预览评审入口

说明：

- “上传资料生成”与“导入用例”属于保留功能，仍然可达
- “预览评审”保留为列表工作流入口，不移除

#### 右侧表格区

用例列表改为表格，而不是卡片清单。第一版建议列如下：

- 名称
- 编号
- 状态结果
- 用例等级
- 执行者
- 执行方式
- 操作

如果现有后端暂时没有完整字段，第一版允许：

- 对缺失字段显示占位
- 用当前已有字段映射，例如状态、优先级、类型、模块

操作列至少保留：

- 进入详情
- 进入评审

### 二、新建测试用例页

新建页改为双栏编辑器结构。

#### 左侧主编辑区

左侧编辑区包含：

- 名称
- 执行方式
- 描述
- 前置条件
- 测试步骤

测试步骤区改为结构化表格编辑器，默认围绕以下列工作：

- 序号
- 步骤描述
- 预期结果

保留现有步骤数据能力，但在视觉上收敛到测试管理常见结构中。若现有自动化步骤模型包含 `action / target / locatorHint / assertion / value` 等字段，第一版可采用以下策略：

- 主表格默认只突出“步骤描述 / 预期结果”
- 自动化增强字段折叠为高级设置或附加信息
- 不让工程字段抢占主视线

#### 右侧基础信息栏

右侧侧栏包含：

- 编号
- 类型
- 用例等级
- 标签
- 模块
- 版本号
- 迭代
- 处理者
- 归属目录
- 关联需求
- 附件

并新增目录选择控件：

- 先选一级目录
- 再选二级目录
- 允许只选一级目录
- 若切换一级目录，不属于该一级目录的二级目录自动清空

### 三、测试用例详情页

详情页与新建页使用同一套双栏版式，避免风格割裂。

差异仅体现在状态与操作上：

- 已存在的用例显示当前状态
- 保留评审、发布、保存等动作
- 已发布用例仍按当前规则限制编辑

评审信息不再挤占主编辑内容，而是保持在右侧动作区或附属面板中。

## 数据模型设计

### 用例目录实体

新增项目维度的测试用例目录实体，建议字段：

- `id`
- `project_id`
- `name`
- `parent_id`
- `order_index`
- `created_at`
- `updated_at`

约束：

- 一级目录：`parent_id = null`
- 二级目录：`parent_id = 一级目录 id`
- 第一版禁止三级及以上目录

### 测试用例目录归属

测试用例新增目录归属字段，建议为：

- `directory_id`

说明：

- 若选择一级目录，则 `directory_id` 指向一级目录
- 若选择二级目录，则 `directory_id` 指向二级目录
- 列表页筛选时需要通过目录父子关系向上聚合

## 交互规则

### 目录筛选

1. 默认进入列表页时展示全部用例
2. 点击一级目录，展示该一级目录及其所有二级目录下的用例
3. 点击二级目录，仅展示该二级目录用例
4. 搜索、状态筛选与目录筛选叠加生效
5. 如果目录下无用例，右侧展示空状态，并保留新建与导入入口

### 用例创建与编辑

1. 新建时允许先填写主编辑区，再补右侧元信息
2. 保存时校验最小必填项：
   - 名称
   - 类型或执行方式（按现有模型映射）
   - 至少一条步骤
3. 目录字段非强制时，用例进入“未分类”
4. 切换目录时实时更新右侧归属信息

### 现有功能保留策略

#### 上传资料生成

保留在列表页顶部工具区，作为次级入口，不进入编辑器内部。

#### 导入用例

保留在列表页顶部工具区，继续复用当前导入能力。

#### 预览评审

保留在列表工作流中，作为顶部工具区入口或列表页快捷动作，不删除。

#### 评审与发布

继续通过详情页和评审页完成，不改变当前业务路径。

## 视觉与布局要求

### 列表页

- 左树右表结构
- 顶部工具区紧凑，符合企业后台风格
- 表格优先，不再使用卡片作为主列表载体
- 目录树与表格在 1440p、2K、4K 下保持稳定比例

### 编辑页

- 左侧编辑区宽于右侧信息栏
- 右侧信息栏固定语义为“基础信息 / 自定义信息 / 流程操作”
- 测试步骤表格为页面重点，优先保证可读性和录入效率

### 统一风格

- 沿用当前项目既有控制台风格
- 不引入花哨动效
- 中文文案统一
- 状态、按钮、字段、空状态遵守现有设计系统

## 实施顺序建议

1. 新增目录数据模型、接口和前端类型
2. 重构测试用例列表页为左树右表结构
3. 重构在线编写页为双栏编辑器
4. 重构详情页与评审侧栏结构
5. 将上传资料生成、导入用例、预览评审入口接回新工作面
6. 补齐测试与回归验证

## 测试与验收

至少覆盖以下验收点：

### 列表页

- 目录树可展开 / 收起
- 一级目录、二级目录筛选正确
- 搜索、状态筛选与目录筛选可叠加
- 上传资料生成、导入用例、预览评审入口仍可达

### 新建页

- 双栏布局正常渲染
- 测试步骤表格可新增、编辑、删除
- 目录选择支持一级 / 二级联动
- 保存成功后进入详情或回到列表的行为正确

### 详情页

- 与新建页共用视觉结构
- 评审与发布动作仍可用
- 已发布状态的只读限制不回归

### 数据

- 目录实体与用例归属关系正确
- 一级目录聚合查询正确
- 二级目录精确查询正确

## 风险

1. 现有测试用例模型没有目录字段，本次需要补真实数据模型与迁移
2. 现有编辑器偏自动化草稿结构，改成更强测试管理导向后，需要妥善安置自动化字段
3. 列表页由卡片转表格后，现有测试断言和页面文案会有较大调整
4. 若上传资料生成、导入用例、预览评审入口摆放不当，可能造成用户以为功能被删除，因此需要在顶层入口明确保留

## 决策结论

本次采用以下方案：

- 列表页：真实两级目录树 + 表格工作面
- 新建页：双栏测试用例编辑器
- 详情页：与新建页统一版式
- 目录模型：目录实体化，测试用例通过目录 ID 挂载
- 保留现有功能：上传资料生成、导入用例、预览评审、评审与发布链路全部保留，仅调整到更合理的 UI 位置
